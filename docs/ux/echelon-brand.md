# EDY SIEM - Echelon Brand System

## Principle

Echelon stands for operational clarity under pressure. The system prioritizes legible signals, hierarchy and confidence, never theatrical security imagery.

## Symbol: Echelon Step

The mark is one continuous three-step shape. The steps represent reading, classification and decision. Its silhouette remains distinct in one color at 16 px.

### Usage

- Use the symbol alone for favicon, collapsed navigation, app icon, GitHub and technical documentation.
- Use the `EDY SIEM` wordmark only where horizontal space is available.
- Digital minimum: 16 px. Clear space: at least 25% of the symbol size.
- Use one brand color at a time. Do not add outlines, shadows, gradients, rotation or 3D effects.

## Interface

- Inter is the product voice; JetBrains Mono is reserved for investigative data.
- Default radius: 8 px. Borders: 1 px. Interaction motion: 120-160 ms.
- Blue is reserved for navigation, focus and primary actions; it is never a severity color.
