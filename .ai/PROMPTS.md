# Task prompt checklist

The repository intentionally does not ship a separate prompt-library directory.
Use this checklist when handing work to an agent:

1. State the target outcome and the paths in scope.
2. State non-goals and protected surfaces, especially API contracts and architecture.
3. Ask for the relevant validation commands and expected evidence.
4. Require a concise summary of changes, risks, and remaining follow-up.
5. For releases, require a clean working tree, commit SHA, CI status, and remote result.

See [AI_HANDOFF.md](AI_HANDOFF.md) for the formal handoff format and
[WORKFLOW.md](WORKFLOW.md) for quality gates.
